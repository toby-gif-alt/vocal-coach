# Salamander Grand Piano samples

These files are a 30-note subset of the Salamander Grand Piano V2 sample set used by the Tone.js examples. The source instrument is a Yamaha C5 grand piano, recorded by Alexander Holm.

- Upstream: https://github.com/Tonejs/audio/tree/master/salamander
- License: Creative Commons Attribution 3.0 Unported (CC BY 3.0)
- License text: https://creativecommons.org/licenses/by/3.0/legalcode
- Attribution: Salamander Grand Piano V2 by Alexander Holm

The filenames and their chromatic pitch roots are mapped in `src/piano-sample-pack.js`. Playback selects the closest root and changes playback rate between anchors. The recordings are never looped.
